# 后台 Runtime 音乐抑制（进行中）

## 实现

客户端 `SoundEngine` 对后台 Runtime 的 `SoundSource.MUSIC` 音频拦截立即播放、延迟播放和 tick 声音排队；首次后台 tick 停止已经播放的 MUSIC 类别。主 Runtime、未配置 MMLF 的独立游戏及其他声音类别不受此规则影响，不修改用户音量设置。音频属于 MUSIC 类别的 Mod 内容也会被视为背景音乐；唱片等其他类别不受影响。

## 问题及处理

多个 Runtime 同时运行时各自播放音乐，产生重叠。按 Runtime 身份和音乐声音类别过滤，继续保留现有交互音效转发。
