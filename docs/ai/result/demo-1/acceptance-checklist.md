# Demo 1 手动验收清单

两个方向各做一遍：NeoForge 当主（`./scripts/run-demo.ps1 -Primary neoforge`），Fabric 当主（`./scripts/run-demo.ps1 -Primary fabric`）。主窗口会先显示"等待其他 Runtime"，后台进入世界后自动进入。

场景：正前方蓝色方块属于 Fabric，橙色方块属于 NeoForge；Fabric 那一侧有 Macaw's 门，NeoForge 那一侧有 Macaw's 活板门。"远端"指不属于主窗口那一端的东西。

| # | 操作 | 预期 | NeoForge 当主 | Fabric 当主 |
|---|---|---|---|---|
| 1 | 观察画面 | 两种颜色的方块和门/活板门同时可见，地面只有一层，没有摩尔纹 | | |
| 2 | 绕着方块走动、慢速转头 | 远端方块位置正确，前后遮挡正确，没有错位或闪烁 | | |
| 3 | 抬头看天空，转头 | 云不闪烁 | | |
| 4 | 空手右键远端测试方块 | 远端方块状态改变，另一种颜色的方块也跟着联动（反向事件） | | |
| 5 | 右键远端的门或活板门 | 打开或关闭，有挥手动作和声音 | | |
| 6 | 走进远端方块 | 被挡住，不能穿过 | | |
| 7 | 中键选取远端的门或活板门 | 快捷栏出现原生图标（不先闪纸张），手上显示原生模型 | | |
| 8 | 拿着它右键地面 | 在地面上放下这个远端物品 | | |
| 9 | 左键破坏一个远端方块 | 方块消失，有破坏粒子 | | |
| 10 | 关闭主窗口 | 几秒内后台进程也全部退出 | | |

已知不在本次验收范围：超快速转头时，屏幕边缘的远端物体会被裁切（已标为未完成）；远端门的物品图标和放置后的门贴图不同，这是 Mod 本身的设计。

结果：每项填"通过"、"不通过"或"不通过 + 现象"。
