# 重投影诊断阶段报告（进行中）

## 实现

`RemoteCompositor` 增加可选诊断开关 `-Dmmlf.reprojectionDiagnostic=true`：红色表示最后一次搜索采样超出投影范围，黄色表示深度无效，紫色表示未找到交点，青色表示深度一致性检查失败，蓝色表示投影齐次坐标无效，绿色表示成功。诊断模式会覆盖深度，只用于观察，不代表正常合成效果。搜索失败颜色仅代表最后一次采样结果，不是像素失败原因的统计或确定根因。默认关闭。正常模式保留深度一致性检查，并拒绝齐次坐标无效的片元。

## 发现与处理

GPU 合成日志以前直接用本 JVM `System.nanoTime()` 减去远端 JVM 的捕获时间，时钟基准尚未经验证；移除了该误导性帧龄值，保留原始捕获时间供后续校准诊断使用。现有帧文件使用普通映射读写和 `VarHandle.fullFence()`，仅有同 JVM 线程测试，不能据此证明跨进程发布顺序。快速旋转时边缘缺失的实际根因尚未确认。
