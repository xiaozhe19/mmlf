# 重投影搜索距离修复（进行中）

## 发现的问题

`RemoteCompositor.farPlane()` 对标准 OpenGL 透视矩阵使用 `b/(a-1)`。按照 `clip.z=a*z+b`、`clip.w=-z`，此式求得的是近裁剪面，远裁剪面应为 `b/(a+1)`。原代码又将结果限制到至少 16，因此当远裁剪面是 256、近裁剪面是 0.05 时，着色器的远端表面搜索上限约为 16 格。远于搜索范围的物体可能被误判为无交点；目前没有证据表明它是快速转头边缘消失的唯一原因。

## 修改

新增 `ProjectionPlanes.far` 计算远平面并处理无穷远或无效矩阵，供 GPU 重投影使用。着色器同时使用当前像素到远平面的射线长度，避免倾斜视线的搜索范围仅按前向距离截断；保留原有深度一致性判断。增加数学单元测试验证已知近平面 0.05、远平面 256，以及无穷远/无效输入。
